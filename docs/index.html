PayPerTask

An agent that hires a worker for a real job onchain and pays in CELO when the work is delivered. Built for the Celo Agents Open for Business hackathon — Verified Agent Payments track. Live on Celo mainnet.

How it works: the agent creates a job with the CELO bounty locked in the contract → the worker submits the finished work onchain → the agent verifies it → the contract releases the bounty to the worker. If the work never comes, the agent can cancel and get the bounty back. No owner, no admin.

Full code, tests and proof of the live run are in the project repository (link added at submission time).
